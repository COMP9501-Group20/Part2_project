# Simulation videos

The five supplementary demonstrations are stored in `videos/` and linked directly from both project READMEs:

- [English](../README.md#simulation-demos)
- [中文](../README_zh.md#simulation-demos)

`videos.json` records each file's relative path, simulator, duration, size and SHA-256 checksum. The videos are included in the repository archive and can be played locally after extraction. G1/Isaac Gym is the runnable training task; GR-1 and GRUtopia demonstrations show additional robot and scene settings.
