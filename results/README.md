# Measured results

No measured course-project simulation results are included yet. Run training and evaluation before adding a result table or performance claim.

`scripts/run.py evaluate` writes `metrics.json` beside a run manifest. `scripts/summarize.py` aggregates those measured files into a CSV and optional figure. Keep the referenced checkpoints and manifests so the result remains traceable.

Unit-test fixtures are temporary synthetic data. Supplementary videos are presented in the README; this directory stores measurements generated by the evaluation scripts.
